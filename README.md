# SwiftShift Logistics Engine

A high-performance, conversion-optimized relocation landing platform architected with modular React functional design systems, Vite tooling, and Tailwind CSS layouts.

---

## 🚀 Architectural Paradigm & Engineering Highlights

This platform was engineered from scratch to demonstrate enterprise-level frontend standards, moving away from monolithic script paradigms toward a decoupled, scalable architecture.

* **Decoupled Data Tier:** All presentation strings, link mappings, and FAQ indices are completely abstracted into a centralized matrix (`src/constants/index.js`). This layout ensures instant localization capabilities and keeps the core JSX presentation node footprint incredibly lean.
* **Modern Layout Refactor:** Swapped out generic parent layout containers for strict semantic HTML elements (`<main>`, `<nav>`, `<footer >`) to pass modern accessibility checking and optimize search engine web indexing visibility.
* **Micro-Interaction System:** Implemented precise interactive spring transformations using Framer Motion primitives across target links and CTA vectors, driving user conversion metrics up via physical element feedback.
* **Intelligent CSS Accordion:** Engineered a pure Tailwind layout accordion grid rule inside the FAQ block utilizing CSS grid fractional dimensions (`grid-rows-[0fr]` transitioning to `grid-rows-[1fr]`). This allows the layout to animate component heights natively without relying on heavy third-party UI execution libraries.

## 💻 Local Workspace Workspace Setup

Follow these workspace commands to run the local optimization development server pipeline:

### 1. Project Cloning & Asset Setup
 Pull down master repository branches
git clone [https://github.com/Sonal-sp/SwiftShift.git](https://github.com/Sonal-sp/SwiftShift.git)

 Step inside the target root directory
cd SwiftShift

### 2. Dependency Matrix Installation
 Install toolchain configuration node modules
npm install

### 3. Initialize Optimization Pipeline
 Fire the Vite local Hot Module Replacement (HMR) runtime server
npm run dev
