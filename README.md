# 🚚 SwiftShift Logistics Engine

A modern, responsive landing page built for a logistics and relocation service. SwiftShift focuses on delivering a clean user experience, fast performance, and a scalable frontend architecture using React, Vite, and Tailwind CSS.

Designed with modular components and reusable data structures, the project demonstrates modern frontend development practices while maintaining excellent readability and maintainability.

---

## ✨ Features

* Responsive design optimized for desktop, tablet, and mobile devices
* Modular React component architecture
* Centralized content management for easy updates
* Smooth animations and interactive UI using Framer Motion
* SEO-friendly semantic HTML structure
* Lightweight and high-performance build powered by Vite
* Accessible and user-friendly interface
* Animated FAQ accordion built using pure Tailwind CSS

---

## 🏗️ Project Architecture

The application follows a modular structure that keeps UI components, content, and styling well organized.

### Centralized Data Management

All static content—including navigation links, feature descriptions, and FAQs—is stored in a single constants file (`src/constants/index.js`). This approach simplifies maintenance and makes future updates or localization significantly easier.

### Semantic HTML

The layout uses semantic elements such as `<main>`, `<nav>`, and `<footer>` to improve accessibility, enhance SEO, and provide a meaningful document structure.

### Interactive User Experience

Framer Motion is used to create subtle animations for buttons, links, and interactive elements, providing a smoother and more engaging browsing experience.

### CSS-Based FAQ Animation

The FAQ section uses Tailwind CSS Grid transitions (`grid-rows-[0fr]` to `grid-rows-[1fr]`) to animate expandable content without relying on additional UI libraries.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Sonal-sp/SwiftShift.git
cd SwiftShift
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
